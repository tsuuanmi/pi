# providers/gemini-web/models

Mirrors `src/providers/gemini-web/models.ts`.

Builds zero-cost, text-only Pi model metadata from the verified daemon capability marker. Only
account-visible Flash and Pro are registered as models. Both advertise one reasoning level; enabling
it selects the internally discovered Extended thinking mode. The browser provider uses conservative
32,000-token context and 8,192-token output limits.
